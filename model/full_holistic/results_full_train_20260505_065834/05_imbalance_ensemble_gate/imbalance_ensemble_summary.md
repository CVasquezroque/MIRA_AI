# Imbalance Ensemble Gate Summary

Official `imbalanced-ensemble` (`imbens`) estimators were used.

This stage audits `classes_` and always scores the probability assigned to `fraud_bool=1`.
It also reports whether `1 - score` would produce ROC-AUC > 0.5 when the original ROC-AUC is below 0.5.

## Validation Search

The search uses the temporal validation month only. Test is never used to select parameters.

- Self-paced Ensemble: `k_bins in [1, 10]`
- Balance Cascade: `replacement in [True, False]`
- EasyEnsemble: `max_samples in [0.5, 1.0]`, `max_features in [0.5, 1.0]`

Score inversion suspected for 3 trial(s); inspect `imbalance_ensemble_validation_search.csv`.

## CatBoost Comparison

Best imbalance ensemble by validation PR-AUC: `imbalance_ensemble_gate | Self-paced Ensemble | validation_selected` val PR-AUC `0.155951`, test PR-AUC `0.162057`. CatBoost baseline val PR-AUC `0.180242`, test PR-AUC `0.217709`. Treat the imbalance ensemble as competitive only if it closes this validation gap and improves operational metrics.
